# Schlauer Kalender (Web-App)

Termine, Wetter, Feiertage und Kochideen für heute. Läuft komplett im Browser, ohne Server und ohne Kosten.

## Kostenlos veröffentlichen mit GitHub Pages

1. Auf github.com ein kostenloses Konto anlegen und anmelden.
2. Oben rechts auf **+ → New repository**. Name z. B. `schlauer-kalender`, **Public** wählen, **Create repository**.
3. Auf der neuen Seite auf **uploading an existing file** klicken. Alle Dateien und den Ordner `icons` aus diesem Ordner hineinziehen (nicht den äußeren Ordner selbst, sondern seinen Inhalt). Unten **Commit changes**.
4. **Settings → Pages**. Bei "Branch" **main** und **/ (root)** wählen, **Save**.
5. Nach etwa einer Minute steht oben die Adresse: `https://DEIN-NAME.github.io/schlauer-kalender/`. Das ist der Link für deine Freunde.

Alternative ohne Konto-Gefummel: auf netlify.com/drop den ganzen Ordner ins Fenster ziehen.

## Für deine Freunde (iPhone)

1. Link in **Safari** öffnen.
2. Stadt eingeben.
3. Unten auf **Teilen → Zum Home-Bildschirm** tippen. Danach startet der Kalender wie eine App.

## Gut zu wissen

- **Daten:** Termine und Einkaufsliste liegen nur auf dem jeweiligen Gerät. Unter Einstellungen gibt es "Daten sichern" und "Daten wiederherstellen".
- **Privatsphäre:** Es gehen nur der Ort (als Koordinaten) und das Jahr an Open-Meteo und Nager.Date. Sonst verlässt nichts das Gerät.
- **Rezepte:** Eigene Gerichte trägst du in `rezepte.js` ein (Anleitung steht oben in der Datei).
- **Updates:** Geänderte Dateien in GitHub erneut hochladen. Beim nächsten Öffnen mit Internet haben deine Freunde die neue Version.
- **Wetterdaten:** Open-Meteo ist für nichtkommerzielle Nutzung kostenlos. Die Quellenangabe steht schon in den Einstellungen.
- **Allergien:** Die Rezepte sind Ideen. Zutaten bei Allergien immer selbst prüfen.
